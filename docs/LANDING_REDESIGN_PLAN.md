# 별숲 수학마을 랜딩 개선 계획

작성일: 2026-10-25
상태: 구현 완료 (2026-10-25)
대상: `index.html` (랜딩페이지) + 랜딩 전용 디자인 기반
방향: **칠판 수업 보드** (교실 칠판 · 분필 수업)
구현 방식: 코드 우선 (새 이미지 생성 없이 HTML/CSS/SVG/JS + 기존 그림 WebP 파생본)

## 1. 한 줄 목표

선생님이 첫 화면의 칠판에서 학년과 학기를 고르고, 30초 안에 마을을 열거나 학급 주소를 복사하게 한다. 마을의 세계관은 설명문이 아니라 칠판에 붙인 실제 마을 그림과 단원 장소로 증명한다.

## 2. 정한 것

- 주 사용자: 수업을 준비하고 학생에게 링크를 건네는 초등 교사.
- 첫 성공 행동: 학년·학기 선택 → `마을 열기` 또는 `학급 주소 복사`.
- 범위: `index.html`과 랜딩 전용 CSS/JS. 1~6학년 마을 화면은 건드리지 않는다.
- 시각 세계: 짙은 칠판, 나무 테두리와 받침, 분필 손글씨, 앰버 `오늘의 수업` 표시, 코랄 밑줄, 세이지 낙서.
- 기존 마을 그림은 버리지 않는다. 칠판에 자석으로 붙인 실제 수업 자료로 써서 제품의 실제 증거로 삼는다.
- 공용 `assets/css/styles.css`는 마을 화면과 공유 중이므로 수정하지 않는다. 랜딩은 별도 `assets/css/landing.css`로 격리한다.

## 3. 방향 계약

- **THESIS**: 오늘 수업을 준비하는 교사의 칠판. 6개 학년이 똑같은 카드로 늘어선 브로셔를 거부한다.
- **OWN-WORLD**: 칠판 `#1B2A24`, 나무 테두리·받침, 분필 흰색, 앰버 `오늘의 수업`, 코랄 밑줄, 세이지 낙서. 학년 선택은 2×3 수업 목록이고, 선택한 칸에 분필 동그라미가 그려진다.
- **STORY**: 교사가 날짜와 학기를 확인하고 → 학년을 고르고 → 단원 장소 5~6곳을 읽고 → 마을을 열거나 학급 주소를 복사한다. 아래에는 실제 마을 사진, 교구, 두 입구, 성장 순환, 교실 사실이 수업 자료처럼 붙어 있다.
- **SIGNATURE**: 학년을 고를 때 선택한 칸에 앰버 분필 링이 그려지고, `오늘의 수업 계획`·메모·입장 주소·복사 주소가 동시에 바뀐다.
- **ANTI-GOALS**: 판타지 RPG 랜딩, 분필 테마만 입힌 브로셔, 가짜 후기·통계, 조작되지 않는 포스터, 어두운 사이버 대시보드.

## 4. 페이지 구조

1. **첫 화면 · 오늘의 수업**
   - 왼쪽: 제목, 한 문장 설명, 4가지 사실, `학년을 누르면 오늘의 수업 계획이 바뀝니다` 손그림 화살표.
   - 오른쪽: `오늘의 수업 목록` 6칸(1~6학년), 학기 전환(1학기/2학기, `지금` 배지), 선택 칸의 분필 링과 `오늘의 수업` 태그.
   - 아래: `오늘의 수업 계획` 단원 장소 목록, `선생님 메모`, 나무 받침의 `마을 열기`·`학급 주소 복사`.
2. **수업 자료 · 단원 장소** — 3~6학년 실제 마을 그림 4장을 2×2 사진판으로 붙이고, 그림과 맞는 대표 단원 장소를 적는다.
3. **수업 자료 · 교구** — 실제 문제 화면 띠 그림을 크게 붙이고, 누르는 그림 교구·손글씨 연습장·단계별 힌트를 분필 메모로 설명.
4. **수업 자료 · 두 입구** — 2학년 새싹숲 지도와 4학년 별숲 밤 풍경을 나란히 두고 두 입구의 차이를 비교.
5. **수업 자료 · 성장 순환** — 분필로 그린 순환도(차시 해결 → 별·씨앗 → 심고 거두기 → 주민 부탁 → 마을 꾸미기)와 놀이 메모 3개.
6. **수업 자료 · 교실에서** — 가입 없음·기기 내 저장·6개 학년/2개 학기·브라우저 바로 열기 4개 메모, `hero.jpg` 마무리 사진, `선생님 교실 도구함`, `이용 흐름`.
7. **마지막 인사** — `오늘의 수업을 시작하세요`와 선택한 학년 입장·복사.
8. **바닥글 · 나무 받침** — 브랜드, 안내 링크, 별숲의 약속, 업데이트 내역, 분필·지우개 소품.

기존 앵커 `#grades`, `#tools`, `#lower`, `#towns`, `#play`, `#teacher`, `#lesson`, `#loop`는 새 위치에 유지한다.

## 5. 시각 시스템

- **색**: 칠판 `#1B2A24`·`#17231E`, 분필 `#F1EBDD`, 보조 분필 `#B9C4B8`, 앰버 `#E9B45C`, 코랄 `#E2775F`, 세이지 `#9CBA9F`, 나무 `#8A6238`·`#5C3D22`.
- **글꼴**: 분필 제목·버튼은 Gaegu, 본문은 Gowun Dodum, 브랜드 명패는 Jua. 마을 화면의 기존 Jua·Gowun Dodum은 그대로 둔다.
- **재질**: 칠판은 미세한 분필 가루 질감(radial gradient), 나무는 8~12px 테두리와 24px 받침. 입체 광택·무거운 그림자는 쓰지 않는다.
- **수업 칸**: 기본은 1px 점선 분필 테두리, 선택은 앰버 3px 손그림 링 + `오늘의 수업` 태그. 회전은 ±0.5° 이내로 하고 본문은 돌리지 않는다.
- **사진**: 실제 마을 그림을 4:3으로 잘라 자석으로 붙인다. 캡션은 분필 메모. 새 일러스트는 만들지 않는다.
- **모션**: 학년 선택 시 링이 그려지고 계획이 짧게 바뀐다. `prefers-reduced-motion`에서는 즉시 바뀐다. 스크롤 패럴랙스는 쓰지 않는다.
- **버튼**: 주 행동은 앰버 바탕 + 어두운 글자 + 부드러운 그림자, 보조 행동은 분필 밑줄. `btn-pulse`는 **선택한 학년의 `마을 열기` 한 곳에만** 적용한다. 학년 칸·복사·도구함에는 동시에 울리지 않는다.

## 6. 문구 원칙

- 첫 제목: `오늘의 수학은, 어느 마을에서?`
- 첫 설명: “학년을 고르면 교과서 단원마다 다른 장소가 열립니다. 학생은 주민이 되어 문제를 풀고, 별과 씨앗으로 마을을 가꿉니다. 설치도 가입도 없이 주소 하나로 시작하세요.”
- 사실: `6개 학년`, `2개 학기`, `기기 내 저장`, `교실용 링크`.
- `관측`이라는 말은 쓰지 않고 `오늘의 수업`, `수업 계획`, `수업 자료`로 통일한다.
- “검토 흐름을 소개하는 자리입니다” 같은 메타 문장은 지운다.
- 확인되지 않은 후기·도입 사례·수상·통계는 넣지 않는다.

## 7. 기술 계획

### 파일

- `index.html`: 랜딩 마크업 전면 교체. `styles.css` 링크 제거, `landing.css`만 로드. `#gradeDialog`·`#gradeTitle`·`#gradeBody`와 죽은 체험 팝업 제거. OG 메타 추가.
- `assets/css/landing.css` (신설): `.landing` 범위의 토큰·칠판·나무 테두리·학년 칸·계획·받침·사진판·다이얼로그·토스트·반응형·모션.
- `assets/js/grades.js`: 학년·학기·장소 데이터는 유지. `doorCard`·`renderDoors`·`renderTowns`·`renderPlays`·`renderMini`·`renderQuickDock`과 `TRIALS`는 랜딩에서 제거. `window.StarforestGrades` 계약은 유지.
- `assets/js/app.js`: 학년·학기 상태, 선택 칸 렌더, 계획 갱신, 복사, 다이얼로그, 해시 입장, 모바일 독, 날짜, 토스트를 새 마크업에 맞게 다시 쓴다.
- `assets/js/history.js`: 2026-10-25 칠판 랜딩 항목 추가, 버전 갱신.
- `assets/js/pwa.js`: 서비스워커 등록은 유지하고, 랜딩에서는 자동 설치 배너를 숨긴다. 설치 안내는 바닥글 메모로 대체.
- `assets/img/landing/` (신설): 기존 그림의 WebP 파생본(640/1200). 원본 JPEG는 폴백.
- `sw.js`: 캐시 버전을 올리고 `landing.css`, `app.js`, `grades.js`, `history.js`, 대표 WebP를 추가. 27MB 전체를 미리 캐시하지 않는다.
- `manifest.json`: 마을 화면과 공유하므로 이번에는 건드리지 않고, 랜딩 `theme-color`만 `#1B2A24`로 바꾼다.
- `docs/LANDING_REDESIGN_PLAN.md`: 이 계획.
- `.impeccable/surfaces/index-html.md`: 칠판 방향 계약으로 교체.
- `PRODUCT.md`: 랜딩 표면의 글꼴 예외 한 줄 추가.
- `DESIGN.md` (신설): 실제 토큰·컴포넌트·모션·반응형·이미지 출처 기록.

### CSS 격리

`styles.css`는 `lower/`, `grade3/`~`grade6/`이 함께 쓴다. 랜딩은 이 파일을 읽지 않고 `landing.css`만 읽는다. 리셋, 건너뛰기 링크, 포커스, 다이얼로그, 토스트, `btn-pulse`는 `landing.css`에 다시 구현한다.

### 상태·예외

- 학년 6개 × 학기 2개 = 12개 상태. 선택한 학년·학기가 칸, 계획, 복사 주소, 입장 주소에 모두 반영된다.
- 1학년 1학기는 실제 데이터가 5곳이므로 `6곳`으로 고정하지 않고 실제 개수를 표시한다.
- 학기 선택은 저장하지 않고 새로고침하면 현재 시즌으로 돌아온다. `지금` 배지는 현재 시즌에만 붙는다.
- JavaScript가 없어도 `<noscript>`에 6개 학년 직행 링크와 1·2학기 링크를 둔다.
- `#grade-1`~`#grade-6`, `#grade-3-s2` 해시 입장은 그대로 동작한다. 선택 상태는 URL 해시에 쓰지 않는다.
- 복사 실패 시 주소를 토스트로 보여 주고, 길면 줄바꿈한다.

### 이미지·성능

- 대표 이미지는 `cwebp`로 640/1200 WebP를 만들고 `<picture>`/`srcset`으로 제공한다. 원본 JPEG는 폴백.
- 사용한 원본: `town-g3`, `town-g4`, `town-g5`, `town-g6`, `map-g2`, `lesson-quiz`, `hero`. 모두 기존 `assets/img/flow/` 자산이다.
- 모든 이미지에 `width`/`height` 또는 `aspect-ratio`를 주고, 첫 화면 아래는 `loading="lazy"`, `decoding="async"`.
- Google Fonts는 Gaegu + Gowun Dodum + Jua를 `display=swap`으로 로드하고, 오프라인에서는 시스템 한글 글꼴로 대체한다.
- 목표: 교실 와이파이에서 LCP 2.0초 이내, CLS 0.1 미만, 롱태스크 200ms 이하.

### 검색·공유

- `title`, `description`을 새 문구에 맞게 다듬는다.
- `og:title`, `og:description`, `og:image`(기존 `hero.jpg`), `og:image:width/height`, `twitter:card`를 추가한다.
- `lang="ko"`, `color-scheme: dark`, `theme-color: #1B2A24`.

## 8. 접근성

- 학년 선택은 실제 `<button>` 6개, 선택 상태는 `aria-pressed`. 분필 링·낙서 SVG는 `aria-hidden`.
- 학기 전환은 `role="group"` + `aria-pressed` 두 버튼. `지금`은 색이 아니라 글자로도 표시.
- 선택한 학년이 바뀌면 작은 상태 줄만 `aria-live="polite"`로 읽어 준다.
- 포커스는 분필 흰색 + 앰버 이중 링. 건너뛰기 링크 유지.
- 다이얼로그는 제목 연결, X 닫기, Escape, 포커스 복귀를 확인한다.
- 명암비는 모든 본문 4.5:1 이상. 코랄은 큰 강조에만 쓴다. `forced-colors`에서도 선택 상태가 보이게 한다.
- `prefers-reduced-motion`에서 링 그리기·펄스·전환을 끈다.
- 모바일 독은 44px 이상 터치 영역, 안전 영역(`env(safe-area-inset-bottom)`) 확보.

## 9. 반응형

- **1440·1280**: 왼쪽 제목 + 오른쪽 2×3 수업 목록, 아래 계획과 나무 받침. 첫 화면에 두 행동이 모두 보인다.
- **1024**: 2열 유지, 제목·칸 크기 축소, 계획 3열 2줄. 나무 받침은 화면 아래 고정 독으로 바뀐다.
- **940 이하**: 세로로 쌓고, 학년 칸 3열, 계획은 자동 배치.
- **720 이하**: 학년 칸 2열, 사진판 1열, 교구·교실 메모 1열.
- **390·320**: 첫 화면에 학년 6칸과 하단 독의 주 행동이 보인다. 320에서도 가로 스크롤이 없다. 360 이하에서는 설명 문단을 숨겨 6칸과 독을 먼저 보여 준다.
- 모바일 독은 다이얼로그가 열리거나 바닥글이 보이면 숨기고, 본문 마지막에 가리지 않도록 여백을 준다.

## 13. 열린 결정

1. **글꼴 배포**: 지금은 Google Fonts + 시스템 폴백. 오프라인 제목까지 완전히 보장하려면 Gaegu·Gowun Dodum·Jua의 한국어 서브셋 woff2를 자체 호스팅한다.
2. **PWA 매니페스트**: 마을 화면은 초록 테마를 유지하므로 매니페스트는 그대로. 랜딩만 칠판색 `theme-color`를 쓴다.
3. **이미지 추가**: 1학년 새싹숲 지도(`map-g1`)는 이번 랜딩에서 쓰지 않고 2학년 지도를 대표로 썼다. 학년별 입구를 모두 보여 주려면 이미지 한 장을 더 배치할 수 있다.
