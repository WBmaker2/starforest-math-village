# 별숲 수학마을 4차 개선 구현 계획 (2026-10-17 확정)

6개 아이디어를 작고 독립적인 순서대로 구현합니다.

## 실행 순서

1(학습지) → 4(랭킹) → 5(오답리포트) → 3(적응형) → 2(프로필) → 6(도감)

## 1. 학습지 인쇄 (공수: 작음)

- 목표: 단원 선택 → 10문제+정답지 종이 학습지.
- 작업:
  - `assets/js/g3-sheet.js` 신설: 학년→단원 선택 UI, 10문항 조립, 정답지(풀이 포함) 분리.
  - 재사용: `g3-pad.js` `generateSet(houseId)`, `low-data.js` `LowPad.generate`.
  - 출력 위치: 선생님 도구함 + 각 단원 차시 목록 "🖨️ 학습지" 버튼.
  - `g3.css`에 `print-sheet` 인쇄 규칙 (`print-diploma` 패턴 복제, 정답지 2페이지).
  - 저학년은 큰 글자·그림 선택지 버전으로 분기.
- 검증: 3학년 곱셈·1학년 숫자 화단 인쇄 미리보기, 정답-풀이 일치 전수 확인.
- 주의: 랜덤 생성이라 "같은 학습지 다시 뽑기"는 출력 일련번호로 대체.
- 상태: 완료 (2026-10-17).

## 4. 우리 반 랭킹 (공수: 작음)

- 목표: 초대된 친구+나의 별·콤보·격파 수 전시판 (서버 없음).
- 작업:
  - `assets/js/g3-friend.js`: 친구 목록에 정렬 뷰 추가 (친구 코드는 펫 단계·격파 수 포함済, 추가 인코딩 불필요).
  - 표시 위치: 친구 초대 카드 아래 "🏆 우리 반 랭킹" (별·최고콤보·수호자 탭 전환).
  - 별숲 신문에 랭킹 1~3위 포함.
- 검증: 친구 3명 초대 후 정렬·탭 전환·신문 반영 확인.
- 주의: 읽기 전용 전시. 진도·별 원본 공유 없음.
- 상태: 완료 (2026-10-17).
