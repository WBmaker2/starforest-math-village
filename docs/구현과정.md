# 별숲 수학마을 구현 과정 기록

별숲 수학마을(마을 입구 안내 + 1~6학년 마을)의 구현 과정을 기록합니다.

## 1. 배경과 구성

- 마을 입구 안내(`index.html`): 칠판 수업 보드에서 학년·학기 선택, 단원 장소 계획, 마을 열기·학급 주소 복사, 실제 마을 그림·교구·두 입구·성장 순환, 교실 도구함.
- 1학년 새싹숲(`lower/?grade=1`)과 2학년 새싹숲(`lower/?grade=2`): 각 6곳·18문항, 그림 터치 교구와 집 성장 배지.
- 3학년 별숲 마을(`grade3/`): 주민 만들기, 마을 산책, 단원 장소 6곳, 텃밭과 꾸미기, 일지와 기록.
- 4학년 별숲 마을(`grade4/`), 5학년(`grade5/`), 6학년(`grade6/`): 학년별 6단원 장소·맞춤 교구·8종 부탁, 공용 엔진 재사용.
- 공용 엔진(`g3-store.js` 등)은 학년 코드를 읽어 단원·핀·부탁·리포트를 바꾸고, 아바타·별·씨앗·텃밭은 공유하고 진도·오답·방문·부탁은 학년별로 나눠 저장합니다.
- 파일은 500줄 이하로 나눕니다.

## 2. 마을 입구 안내 구조

- 2026-10-25부터 `index.html`은 교실 칠판을 닮은 '칠판 수업 보드'입니다. 학년 6칸과 학기 전환, 선택한 학년의 단원 장소 계획, `마을 열기`·`학급 주소 복사`를 첫 화면에 둡니다.
- 실제 마을 그림과 문제 화면은 칠판에 붙인 수업 자료로 보여 주고, 새싹숲·별숲 입구와 별·씨앗 성장 순환, 교실 사용 약속을 이어서 설명합니다.
- 학년 주소(`#grade-1`~`#grade-6`, `#grade-3-s2`)로 열면 해당 학년 마을로 바로 이동합니다.
- 다음 단계 버튼(`마을 열기`)에는 금빛 펄스(`btn-pulse`)를 한 화면에 하나만 적용합니다.

## 3. 3학년 별숲 마을 구조

- 아바타: 200x250 표준 캔버스 기반 8단계 레이어(몸통 SVG → 신발 한 켤레 → 하의 → 상의 → 머리 → 표정 → 장식 → 모자) 공용 렌더러(`G3Avatar.mountRig`)를 마을 산책 토큰과 대화창에 연결합니다.
- 단원 장소 6곳(곱셈·나눗셈·원·분수·들이와 무게·그림그래프): 차시 목록, 직접 만든 문항과 단계별 풀이, 별 보상까지 풀이가 이어집니다.
- 양방향 교구(`g3-visuals.js`): 묶음·바구니 선택 세기, 원 반지름 조절, 분수 칸 색칠, 비커·저울 채우기, 그림그래프 도장 찍기를 지원합니다.
- 텃밭·꾸미기·장터·강가·꽃 배합·그림 감별 놀이와 주민 부탁 8종, 수집 카드 10종을 갖췄습니다.
- 기록은 `starforest-g3` 키로 브라우저에 저장합니다. 이전 키(`math-walk-g3`)에 기록이 있으면 이어서 불러옵니다.
