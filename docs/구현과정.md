# 별숲 수학마을 구현 과정 기록

별숲 수학마을(마을 입구 안내 + 3학년 별숲 마을 + 1·2학년 새싹숲 마을)의 구현 과정을 기록합니다.

## 1. 배경과 구성

- 마을 입구 안내(`index.html`): 학년 입구 6종, 학습 도구, 새싹숲, 별숲, 성장 순환, 마을 놀이, 교실 도구함, 의견함.
- 3학년 별숲 마을(`grade3/`): 주민 만들기, 마을 산책, 단원 장소 6곳, 텃밭과 꾸미기, 일지와 기록.
- 1·2학년 새싹숲 마을(`lower/`): 큰 그림과 큰 단추로 푸는 산책 마을.
- 파일은 500줄 이하로 나눕니다.

## 2. 마을 입구 안내 구조

- 학년 카드 6종(1·2학년 새싹숲, 3~6학년 별숲)과 단원 장소 목록, 바로 체험 문제를 담았습니다.
- 학년 주소(`#grade-1`~`#grade-6`)로 열면 해당 학년 체험창이 바로 실행됩니다.
- 다음 단계 버튼(학년 고르기, 마을 열기, 체험 문제 선택)에는 금빛 펄스(`btn-pulse`)를 적용합니다.

## 3. 3학년 별숲 마을 구조

- 아바타: 200x250 표준 캔버스 기반 8단계 레이어(몸통 SVG → 신발 한 켤레 → 하의 → 상의 → 머리 → 표정 → 장식 → 모자) 공용 렌더러(`G3Avatar.mountRig`)를 마을 산책 토큰과 대화창에 연결합니다.
- 단원 장소 6곳(곱셈·나눗셈·원·분수·들이와 무게·그림그래프): 차시 목록, 직접 만든 문항과 단계별 풀이, 별 보상까지 풀이가 이어집니다.
- 양방향 교구(`g3-visuals.js`): 묶음·바구니 선택 세기, 원 반지름 조절, 분수 칸 색칠, 비커·저울 채우기, 그림그래프 도장 찍기를 지원합니다.
- 텃밭·꾸미기·장터·강가·꽃 배합·그림 감별 놀이와 주민 부탁 8종, 수집 카드 10종을 갖췄습니다.
- 기록은 `starforest-g3` 키로 브라우저에 저장합니다. 이전 키(`math-walk-g3`)에 기록이 있으면 이어서 불러옵니다.
