# 마을 화면 UI/UX 개선 계획

2026-10-26 · 구현 완료 (1~6단계 적용)

이 문서는 1학년 새싹숲(`lower/`)과 3~6학년 별숲 마을(`grade3/`~`grade6/`)의 **입구·지도 화면** 개선 계획과 구현 결과를 함께 기록합니다. 2026-10-26에 1단계부터 6단계까지 적용했습니다.

## 이번에 정한 것

- **범위**: 각 마을의 첫 화면, 상단 메뉴, 지도와 '다음 행동'까지. 집 안 대화·문제 풀이·텃밭·꾸미기 내부는 다음 단계로 미룹니다.
- **방향**: 지금의 따뜻한 그림책 마을 세계관을 유지하고, 공통 '마을 광장' 셸과 학년별 구역 색으로 정교화합니다. 랜딩의 칠판 스타일은 마을에 강제로 이식하지 않습니다.
- **첫 성공**: 학생이 학급 링크로 들어와 **5초 안에 지도에서 오늘의 단원 집을 찾고 들어가기**. 교사가 설명을 더 하지 않아도 되는 것이 기준입니다.

## 1. 지금 화면에서 확인한 것

2026-10-26에 5개 마을을 1440×900과 390×844에서 직접 열어 확인했습니다.

1. **첫 화면이 마을이 아니라 앱 소개와 주민 만들기입니다.**
   - 3~6학년: 상단 메뉴 → 큰 제목·설명 → 구역 바 → 주민 만들기 카드가 먼저 나오고, 지도는 첫 화면 아래로 밀립니다.
   - 1·2학년: 지도가 조금 더 위에 있지만, '함께 산책하는 주민' 카드와 설명이 먼저 나옵니다.
   - 학생이 링크로 들어왔을 때 "어디로 가야 하지?"보다 "이 화면은 무엇인가?"를 먼저 읽게 됩니다.

2. **상단 메뉴가 이미 넘칩니다.**
   - 1440에서도 학년 6개 + 학기 전환 단추 + 별·씨앗 + 소리 + 칠판 모드가 한 줄에 들어가지 않아, 오른쪽 금빛 단추가 잘립니다.
   - 390에서는 메뉴가 3줄(약 230px)이 되어 첫 화면의 4분의 1 이상을 차지합니다.
   - 현재 학년이 메뉴 알약, eyebrow, 큰 제목에서 세 번 반복됩니다.

3. **지도가 가장 좋은 자산인데 가장 아래에 있습니다.**
   - 지도 그림은 손맛이 살아 있고, 집·주민·길·낮/밤 분위기가 이미 훌륭합니다.
   - 그런데 지도는 카드 5~6번째에 있고, 지도 위에는 '오늘 할 일' 작은 알약, 시간대 버튼 3개, 집 이름표가 겹칩니다.
   - 390에서는 지도가 약 350px 높이로 줄고, 이동 단추는 지도 아래로 밀려 스크롤해야 합니다.

4. **지도 핀 상태가 구분되지 않습니다.**
   - 시작 상태에서는 여섯 집 모두 `🌱 시작전`으로 똑같이 보입니다.
   - 실제로는 `g3-map.js`가 `lv-0`·`lv-1`·`lv-max` 상태와 `unitProgress`를 이미 계산하고 있습니다. 상태를 **보여 주는 방식**만 고치면 됩니다.
   - `nextTodoTask()`는 이미 "오늘 풀 집"을 정확히 계산합니다. 이 기능이 작은 나침반 알약에 묻혀 있습니다.

5. **카드 9~10장이 모두 같은 무게입니다.**
   - 주민 만들기, 뽑기, 마을 산책, 텃밭, 부엌·장터, 꾸미기, 부탁, 도감, 일지·기록이 모두 흰 카드입니다.
   - 매일 쓰는 흐름(지도 → 집 → 문제)과 가끔 쓰는 흐름(뽑기, 도감, 기록)이 같은 크기로 보입니다.
   - 구역 바 아이콘이 `👗 🗺️ 🌱 🏡 🪪` 이모지라 그림책 마을의 손그림 자산과 따로 놉니다.

6. **'다음 단계' 버튼이 여러 개입니다.**
   - `btn-pulse`가 '마을로 나가기', '별사탕 주기', 학기 전환, PWA 설치, 지도 나침반에 동시에 걸릴 수 있습니다.
   - PWA 설치 배너가 화면 아래를 덮어 지도 조작과 이동 단추를 가립니다.
   - 학생이 실제로 눌러야 하는 '오늘의 집 들어가기'에는 고정된 주 행동이 없습니다.

## 2. 개선 원칙

1. **지도가 첫 화면이다.** 마을 화면의 첫 성공은 "지도를 보고 오늘의 집으로 들어가기"입니다.
2. **오늘의 길은 하나.** 이미 계산되는 `nextTodoTask()`를 화면의 주 행동으로 승격합니다.
3. **같은 세계, 다른 동네.** 구조와 컴포넌트는 공유하고, 학년별 구역 색·표지·문구만 다르게 합니다.
4. **큰 손가락, 짧은 문장.** 1·2학년은 더 큰 단추와 읽어주기, 3~6학년은 진행 상태와 별을 또렷하게.
5. **학습 엔진은 그대로.** 문항·저장 구조·기존 ID와 `data-*` 훅을 바꾸지 않습니다.
6. **장식은 그림으로, 기능은 글자로.** 이모지 아이콘을 인라인 SVG·기존 일러스트로 바꿉니다.
7. **한 화면에 펄스 하나.** 다음 단계 버튼 하나에만 금빛 펄스를 겁니다. 학기 전환·설치·뽑기에는 걸지 않습니다.

## 3. 새 구조: 마을 광장 셸

마을 화면을 '앱 대시보드'가 아니라 **마을 광장에 들어선 느낌**으로 바꿉니다. 지도가 무대이고, 나머지는 지도 아래 '마을 살림'으로 물러납니다.

### 데스크톱

```
┌ 표지판 바 ─ 별숲 수학마을 · 3학년 별숲 · 별 12 · 씨앗 3 · 마을 메뉴 ┐
├──────────────────────────────────────────────────────────────┤
│  [마을 표지판]  3학년 별숲 · 곱셈 방앗간 마을   [2학기]        │
│  ┌────────────────────────────────────────────────────────┐  │
│  │                    지도 (60~70vh)                       │  │
│  │  [오늘의 길]                                  [낮/밤]  │  │
│  │      집 · 주민 · 길 · 내 주민 · 다음 집 깃발           │  │
│  └────────────────────────────────────────────────────────┘  │
│  [오늘의 길: 곱셈 방앗간 · 1차시 풀기 →]   [들어가기]         │
├──────────────────────────────────────────────────────────────┤
│  마을 살림: 내 주민 | 텃밭·부엌 | 꾸미기·부탁 | 도감·기록      │
├──────────────────────────────────────────────────────────────┤
│  깊은 화면 (펼칠 때만: 옷장, 뽑기, 텃밭, 기록 …)              │
└──────────────────────────────────────────────────────────────┘
```

### 모바일

```
┌ 별숲 수학마을            별 12 · 씨앗 3 · ☰ ┐
│ 3학년 별숲 · 곱셈 방앗간 마을     [2학기]   │
├────────────────────────────────────────────┤
│                                            │
│              지도 (55~60vh)                │
│   [오늘의 길]                              │
│   집 · 주민 · 다음 집 깃발                 │
│                          [이동 패드]       │
├────────────────────────────────────────────┤
│ [곱셈 방앗간 · 1차시 풀기 →]  [들어가기]    │
├────────────────────────────────────────────┤
│ 내 주민 | 텃밭·부엌 | 꾸미기·부탁 | 도감·기록 │
├────────────────────────────────────────────┤
│ 깊은 화면 (아래로 펼침)                     │
└────────────────────────────────────────────┘
```

### 공통 컴포넌트

- **표지판 바**: 브랜드, 현재 마을, 학년 마을 선택, 학기, 별·씨앗, 마을 메뉴.
- **마을 표지판**: 나무 팻말 위에 학년·학기·마을 이름·한 줄 안내. 기존 큰 제목을 여기에 얹습니다.
- **지도 무대**: 나무·종이 프레임, 지도, 오늘의 길, 시간대 칩, 핀, 내 주민.
- **오늘의 길**: `nextTodoTask()` 결과를 큰 카드 하나로. 누르면 해당 집으로 이동하거나 들어갑니다.
- **장소 시트**: 핀을 누르면 집 이름·단원·진행(`n/total`)·별·`들어가기`를 보여 주는 작은 시트. 데스크톱은 핀 옆 팝오버, 모바일은 아래에서 올라오는 시트.
- **마을 살림 허브**: 큰 그림 타일 4개. 각 타일은 실제 그림, 한 줄 상태, 행동 하나.
- **첫 실행 시트**: 이름 → 모습 → 마을로. 뽑기와 긴 옷장은 첫 실행에서 숨깁니다.
- **하단 독**: 모바일에서 허브 구역을 오갈 때만. 지도 조작과 겹치지 않게 지도 화면에서는 숨깁니다.

### 타이포·색·간격

- **글꼴**: 마을 이름·집 이름·큰 숫자는 Jua, 본문·버튼·라벨·상태는 Gowun Dodum. Jua를 작은 UI 라벨에 쓰지 않습니다.
- **크기**: 제품 화면이므로 clamp 대신 고정 단계(28/24/20/17/15/13)를 씁니다. 지도 표지판만 30~40px까지 허용합니다.
- **간격**: 8px 격자. 카드 모서리 18~22px, 지도 프레임 24px, 알약 999px.
- **색**: 기존 `--leaf`·`--sun`·`--paper`·`--ink`를 유지합니다. 학년별 `--district`는 **지도 프레임·표지 도장·핀 테두리·허브 표식**에만 쓰고, 주 행동 버튼은 기존 `--sun`(어두운 글자)과 `--leaf`(흰 글자)를 유지해 대비를 지킵니다.
- **그림자**: 부드러운 그림자 한 종류. 하드 오프셋 그림자·유리·블러 장식은 쓰지 않습니다.
- **모션**: 150~250ms. 핀 상태 변화·시트 열기·지도 이동만. 페이지 로드 연출은 넣지 않습니다.

## 4. 학년별 구역 키트

구조는 같고, **색·표지 도장·지도·한 줄 문구**만 다르게 합니다. 새 일러스트를 대량로 만들지 않고 기존 지도·집·작물·주민 그림을 재사용합니다.

| 마을 | 구역 색 (초안) | 표지 도장 | 지도 자산 | 한 줄 문구 |
|---|---|---|---|---|
| 1학년 새싹숲 | 새싹 초록 `#7FA36B` / 깊은 `#3F6B45` | 새싹잎 + 꽃 | `map-g1.jpg`, `map-g1s1.jpg` | 그림을 누르면 집에 들어가요 |
| 2학년 새싹숲 | 하늘 파랑 `#6FA3C2` / 깊은 `#35617A` | 시계탑 + 자리수 블록 | `map-g2.jpg`, `map-g2s1.jpg` | 자리수 텃밭에서 오늘의 집을 찾아요 |
| 3학년 별숲 | 방앗간 꿀색 `#C08A3E` / 깊은 `#7A5423` | 물레방아 + 밀 이삭 | `map-a.jpg`(2학기), `town-g3s1.jpg`(1학기) | 방앗간에서 오늘의 문제를 풀어요 |
| 4학년 별숲 | 전망대 보라 `#7A78B8` / 깊은 `#434273` | 망원경 + 꺾은선 | `town-g4.jpg`, `town-g4s1.jpg` | 전망대에서 그래프를 읽어요 |
| 5학년 별숲 | 과수원 사과 `#C06A54` / 깊은 `#7C382C` | 사과 + 자 | `town-g5.jpg`, `town-g5s1.jpg` | 과수원에서 수확하고 재어요 |

- 색은 **초안**입니다. 실제 적용 전에 각 색 위의 글자 대비를 확인하고, 필요하면 깊은 색만 버튼에 씁니다.
- 3학년 2학기 지도는 현재 `map-a.jpg`라 다른 학년처럼 전용 지도가 아닙니다. 이번에는 표지 도장(`house-mul.jpg` 계열)으로 정체성을 보완하고, 전용 지도 제작은 별도 자산 결정으로 미룹니다.
- 1·2학년은 같은 새싹숲이지만 지도·집 이름·색이 다릅니다. 두 마을이 한 화면에서 섞이지 않게 현재 학년을 표지판에 크게 표시합니다.

## 5. 화면별 작업

### 5.1 상단 표지판 바

- 학년 링크 7개를 없애고 **`학년 마을` 선택 하나**로 모읍니다. 6개 학년 + 1·2학기 + 지금 시즌을 한 팝오버에서 고릅니다.
- 현재 학년·마을 이름은 표지판에 한 번만 크게 보여 줍니다.
- 학기 전환은 `[1학기 | 2학기]` 조각 단추로. `g3-sem.js`가 만드는 `#semSwitchBtn`을 새 자리로 옮기고 **펄스를 제거**합니다.
- 소리·칠판 모드·설치·선생님 도구는 `마을 메뉴` 안으로. 별·씨앗은 항상 보이게.
- 목표: 데스크톱 1줄(높이 72px 이하), 모바일 2줄(높이 120px 이하), 320~1440에서 가로 넘침 없음.
- `zonebar`가 남는 경우 `top`을 새 바 높이 변수에 맞춥니다. 모바일에서는 구역 바를 하단 독으로 바꾸는 안을 검토합니다.

### 5.2 마을 표지판과 지도 무대

- 큰 제목·eyebrow·설명을 **나무 표지판 하나**로 묶습니다. 기존 h1 문구는 유지하고, 학년·학기·마을 이름은 작은 칩으로.
- 지도 섹션을 표지판 바로 뒤로 옮깁니다. 주민 만들기·뽑기·텃밭은 지도 아래 허브로 내립니다.
- 지도는 카드 안쪽 여백을 벗어나 콘텐츠 폭에 꽉 차게. `#mapwrap`·`#mapimg`·`#token`·핀·주민·`#todoCompass`·`#mapTimeBar`는 그대로 두고 **프레임과 배치만** 바꿉니다.
- 지도 최소 높이: 데스크톱 60vh, 모바일 55vh. `aspect-ratio: 1200 / 896`을 유지해 그림이 잘리지 않게.
- `#friendBar`는 지도 바로 아래 또는 지도 HUD 안으로. 지도 위에 겹쳐 이름표를 가리지 않게.
- 지도 로딩 전에는 같은 비율의 종이 바탕과 "마을을 펼치는 중" 스켈레톤. 레이아웃 이동(CLS)을 막습니다.

### 5.3 오늘의 길·핀·장소 시트

- `#todoCompass`를 작은 알약에서 **지도 위 큰 '오늘의 길' 카드**로 승격합니다. 문구와 동작은 기존 `nextTodoTask()`를 그대로 사용합니다.
- 지도 핀의 `lv-0`·`lv-1`·`lv-max` 상태를 시각화합니다.
  - 시작 전: 차분한 테두리와 집 이름만.
  - 성장 중: 구역 색 점 + `2/6` 같은 작은 진행 표시.
  - 마스터: 작은 별·도장. 색만으로 구분하지 않고 모양·글자도 함께.
  - '다음 집' 하나에만 작은 깃발. 나머지 핀에는 상태 배지를 항상 띄우지 않습니다.
- 핀을 누르면 장소 시트: 집 이름, 단원, `푼 차시 / 전체 차시`, 별, `들어가기`, `이 집 기록`. 기존 `unitProgress()`와 `enter()`를 재사용합니다.
- `#enterBtn`은 집 앞에서만 뜨는 숨은 단추가 아니라, 지도 아래 **고정된 주 행동**으로. 집 앞이 아니면 "오늘의 길"을, 집 앞이면 "○○ 들어가기"를 보여 줍니다.
- 이동: 키보드 방향키·WASD 유지. 모바일은 지도 오른쪽 아래에 4방향 패드(48px 이상)를 붙이고, 지도 탭 이동도 유지합니다. 패드가 지도 이름표를 가리지 않게 안전 영역을 둡니다.
- 시간대: `☀️ 낮 / 🌇 노을 / 🌙 밤` 세 버튼을 지도 위에 늘 띄우지 않고, `낮` 칩 하나 + 팝오버로. 선택은 기존처럼 저장합니다.
- 나침반·시간대·친밀도가 서로 겹치지 않도록 지도 안에 **HUD 구역**을 나눕니다.

### 5.4 마을 살림 허브

- 흩어진 카드를 4개 타일로 묶습니다.
  - **내 주민**: 아바타, 이름, 옷장, 뽑기.
  - **텃밭·부엌**: 씨앗, 작물, 장터, 요리, 강가·꽃·모눈 놀이.
  - **꾸미기·부탁**: 집 꾸미기, 주민 부탁, 수집 도감.
  - **도감·기록**: 일지, 지도, 기록, 주민증, 학습 리포트.
- 타일마다 실제 그림(작물·집·주민·도장)과 한 줄 상태, 행동 하나. 같은 흰 카드 4장이 아니라 그림이 있는 살림 타일로.
- 기존 섹션과 앵커(`#avatar`, `#farm`, `#gachaSec`, `#note` 등)는 유지합니다. 저학년에서 `grade3/index.html#avatar`·`#farm`로 보내는 링크가 깨지면 안 됩니다.
- 타일을 누르면 해당 섹션이 펼쳐지고, 지도로 돌아오는 `마을로` 단추를 둡니다. 한 번에 한 구역만 펼칩니다.

### 5.5 첫 실행·재방문

- **첫 실행**: 지도는 이미 보이게 두고, 그 위/아래에 3단계 시트(이름 → 모습 → 마을로). 뽑기·긴 옷장은 숨깁니다. 이름을 저장하면 시트가 닫히고 '오늘의 길'이 펄스로 안내합니다.
- **재방문**: 주민은 표지판 바 또는 허브의 작은 카드로. '마을로 나가기'를 매번 크게 반복하지 않습니다.
- **아바타가 없을 때**: `nextTodoTask()`가 이미 "나만의 주민 이름 짓기"를 반환합니다. 이 문구를 그대로 첫 행동으로 씁니다.
- **다 끝났을 때**: "오늘의 여섯 집을 다 걸었어요. 텃밭을 가꿔 볼까요?"처럼 다음 놀이를 제안합니다. 빈 화면에 "없음"만 두지 않습니다.
- **오프라인**: 지도·마지막 진도는 그대로. 저장이 안 되는 동작만 짧게 알립니다.

### 5.6 저학년(1·2학년)

- 같은 셸을 쓰되 단추 최소 52px, 문장은 한 줄, 설명은 접어 둡니다.
- '오늘의 길'과 집 이름에 읽어주기(기존 TTS)를 답니다.
- 1학년/2학년 전환은 학년 선택 안으로. 지도 위에 두 알약을 늘 띄우지 않습니다.
- 큰 그림 단추 3개는 그대로. 글자를 읽지 않아도 집에 들어갈 수 있게 유지합니다.

### 5.7 상태·접근성·모션

- 핀은 실제 `<button>`, 이름과 상태를 함께 읽힙니다. 장식 그림은 `aria-hidden`.
- 포커스 3px, 건너뛰기 링크, `aria-current`, 장소 시트 포커스 트랩과 복귀.
- 색만으로 상태를 구분하지 않습니다. 점·별·글자를 함께.
- `prefers-reduced-motion`: 핀 깜빡임·걷기·펄스·시트 전환을 즉시로.
- `forced-colors`: 선택·포커스가 시스템 색으로 보이게.
- PWA 설치 배너는 지도 위에 띄우지 않습니다. 첫 문제를 푼 뒤 허브 안쪽 안내로 바꾸거나, 닫기 쉬운 작은 줄로.
- 200% 확대, 320px 폭, 가로 스크롤 없음.

## 10. 열린 결정

1. **모바일 구역 이동**: 하단 독 vs 상단 구역 바. 추천은 하단 독(지도 화면에서는 숨김). 1·2학년 손가락으로 검증 후 확정.
2. **표지판 제목**: 기존 h1 문구를 크게 유지 vs 짧은 마을 이름만. 추천은 기존 h1 유지 + 학년·학기 칩.
3. **시간대 조작**: 학생 화면에 유지 vs 설정으로 이동. 추천은 작은 `낮` 칩 + 팝오버, 선택 저장.
4. **3학년 2학기 지도**: 현재 `map-a.jpg` 유지 vs `town-g3.jpg` 승격/새 지도. 추천은 이번에는 유지하고 표지 도장으로 보완, 자산은 나중에 결정.
5. **첫 실행 형태**: 지도 위 시트 vs 지도 아래 인라인 카드. 추천은 첫 실행만 3단계 시트, 재방문은 인라인 카드. 지도를 가리지 않음.
6. **모바일 설명문**: 한 줄 유지 vs 숨김. 추천은 한 줄만 유지.

- **모바일 구역 이동**: 하단 독으로 확정. 그룹을 펼쳤을 때만 보이고 지도 화면에서는 숨긴다.

- **지도 로딩**: 종이 바탕과 `마을을 펼치는 중` 스켈레톤으로 4:3 높이를 먼저 잡아 레이아웃 이동을 막는다.
- **오프라인**: 지도·저장된 기록은 그대로 열리고, 연결이 끊기거나 돌아오면 짧은 안내를 보여 준다.
- **PWA**: 지도 위 자동 배너를 없애고 마을 메뉴의 `앱으로 설치`로 옮겼다.
- **검증**: 5개 마을 × 320/390/768/1024/1280/1440, 첫 실행·아바타·핀/시트/대화·오늘의 길·허브·학기 1학기·인쇄·오프라인을 확인했다. `impeccable detect`의 기능·대비·이미지 문제는 0이고, 기존 크림색 배경 취향 경고만 의도적 예외로 남겼다.
