- 목표: 오답 교실이 같은 문제 반복이 아니라 숫자만 바뀐 쌍둥이 문제를 내서 진짜 이해를 확인.
- 작업:
  - `assets/js/g3-questions.js`·`g4-data.js`·`g5-data.js`·`g6-data.js`·`low-data.js`: 문항에 유형 태그 병기 (기존 `q/a/steps` 유지, 태그 없는 구 문항은 기존 동작).
  - `assets/js/g3-pad.js`: 유형별 쌍둥이 생성기 (`twinFor`).
  - `assets/js/g3-dialog.js` 오답 모드: 쌍둥이 우선 출제, 쌍둥이까지 맞히면 완전 정복 처리.
  - `low-app.js`: 저학년 오답도 동일 규칙.
- 검증: 유형별 정답 일치 단위 테스트 + 오답 왕복 실기.
- 상태: 완료 (2026-10-17).
