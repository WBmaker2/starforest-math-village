# 별숲 수학마을 5차 개선 구현 계획 (2026-10-19 확정)

3개 아이디어를 작고 독립적인 순서대로 구현합니다.

## 실행 순서

1(유형태그) → 2(이해도추적) → 3(리포트인쇄)

## 1. 문항 유형 태그 시스템 (공수: 중간)

- 목표: 모든 문항에 "유형 태그"를 달아서 개념별 이해도를 추적할 수 있는 기반 구축.
- 작업:
  - `assets/js/g3-questions.js`: 3학년 문항에 `tag` 필드 추가 (예: `{ q: "20 × 3 = ?", a: "60", tag: "g3-mul-tens", steps: [...] }`).
  - `assets/js/g4-data.js`·`g5-data.js`·`g6-data.js`: 4~6학년 문항에도 `tag` 필드 추가.
  - `assets/js/low-data.js`: 1·2학년 문항에도 `tag` 필드 추가.
  - `assets/js/g3-tag-map.js` (신설): 학년별·단원별 태그 정의 테이블 (예: `"g3-mul-tens": "몇십 곱하기 몇"`, `"g4-frac-add": "분모가 같은 분수 덧셈"`).
  - 기존 문항은 `tag` 없는 경우 `lid`에서 자동 생성 (하위 호환).
- 검증: 3학년 곱셈·나눗셈 문항 전수에 태그 부여 확인 + 랜덤 문항 추출 시 태그 출력 테스트.
- 주의: 태그命名 규칙은 학년+단원+세부유형 (예: `g3-mul-carry`, `g4-frac-sub`).
- 상태: 완료 (2026-10-19).

## 2. 개념 이해도 추적 + 적응형 학습 경로 (공수: 중간)

- 목표: 문항 유형별 성공률을 추적하고, 취약 개념을 집중 출제하는 적응형 학습 경로 제공.
- 작업:
  - `assets/js/g3-store.js`: `wrong` 배열에 `tag` 필드 저장 확장 (기존 `{ lesson, q, at }` → `{ lesson, q, tag, at }`).
  - `assets/js/g3-understand.js` (신설):
    - `recordSolved(tag, correct)`: 풀이 결과 기록 (최근 50문).
    - `getWeakTags()`: 성공률 60% 미만 유형 TOP 3 반환.
    - `getMasteredTags()`: 성공률 90% 이상 유형 목록 반환.
    - `getFocusList()`: 취약 유형 5문제 + 랜덤 5문제 = 10문제 생성.
  - `assets/js/g3-dialog.js`:
    - 오답 기록 시 `tag` 함께 저장.
    - "취약 개념 집중 연습" 모드 추가 (초록색 버튼, 약점 5문제 + 랜덤 5문제).
    - 풀이 후 "현재 이해도" 표시 (예: "곱셈 올림: 80% 달성!").
  - `assets/js/g3-map.js`: 마을 지도에 "이해도 현황판" 추가 (단원별 색으로 표시: 초록=숙달, 노랑=보통, 빨강=취약).
  - `low-app.js`: 저학년도 동일 로직 적용 (단, 태그는 `low-add`, `low-sub` 등 단순화).
- 검증:
  - 오답 10건 투입 후 `getWeakTags()` 결과 확인.
  - "취약 개념 집중 연습" 모드에서 약점 유형 우선 출제 확인.
  - 마을 지도 이해도 색상 반영 확인.
- 주의: 적응형 난이도(`g3-tune.js`의 `adaptLevel`)는 숫자 범위 조절, 이 기능은 개념 우선 출제. 두 시스템은 독립적으로 동작.
- 상태: 완료 (2026-10-19).

## 3. 학습 리포트 인쇄 (공수: 작음)

- 목표: 오늘/이번 주 학습 분석을 종이로 출력하여 학생·학부모·교사 공유.
- 작업:
  - `assets/js/g3-report.js`: `print-learning-report()` 함수 추가.
    - 섹션 1: 오늘 푼 문제 수, 성공률, 획득 별.
    - 섹션 2: 이번 주 약점 유형 TOP 3 (태그별 성공률).
    - 섹션 3: 숙달 유형 목록 (성공률 90% 이상).
    - 섹션 4: 다음 학습 제안 (취약 유형 5문제 + 추천 학습 경로).
  - `assets/css/g3.css`: `print-learning-report` 인쇄 규칙 추가 (`print-diploma` 패턴 재사용, A4 1페이지).
  - 출력 위치:
    - 선생님 도구함 "📊 학습 리포트" 버튼.
    - 각 단원 대화창 하단 "📊 오늘의 학습 리포트" 버튼.
  - 저학년은 이모지·그림 중심으로 간결하게.
- 검증:
  - 3학년 곱셈 10문제 풀이 후 리포트 출력 → 약점 유형 TOP 3 정확성 확인.
  - 인쇄 미리보기 A4 1장 분량 확인.
  - 저학년 버전 그림·이모지 표시 확인.
- 주의: localStorage 데이터만 사용하므로 새로고침 시 초기화되지 않음.
- 상태: 완료 (2026-10-19).

## 공통 규칙

- 버전 파라미터 `?v=` 통일 상향, `btn-pulse` 다음 단계 버튼 유지.
- `docs/UPDATELOG.md`·`docs/구현과정.md`·`README.md` 쉬운 말 기록.
- 저학년 트랙과 고학년 배율 분리 유지.
- 모든 인쇄 기능은 `print-diploma` CSS 패턴 재사용.
- 태그命名 규칙: `학년-단원-세부유형` (예: `g3-mul-carry`, `g4-frac-add`).

## 구현 우선순위

1. **1번 (문항 유형 태그)**: 전체 시스템의 기반. 먼저 구현해야 2번·3번 가능.
2. **2번 (이해도 추적 + 적응형)**: 학습 효과 핵심. 1번 완료 후 즉시 진행.
3. **3번 (리포트 인쇄)**: 부가 기능. 2번 완료 후 진행.

## 예상 효과

- **학생**: 본인이 어떤 개념을 잘하고 못하는지 명확히 파악 → 자기 주도 학습.
- **교사**: 학급 전체 약점 분석 → 수업 설계 참고 (인쇄물로 공유).
- **학부모**: 자녀 학습 현황을 종이로 확인 → 안심.

## 기술적 제약

- 백엔드 없이 localStorage만 사용 → 개인별 데이터만 추적 가능.
- 학급 전체 통계는 불가 (교사 도구함에서 "인쇄"로 공유).
- 태그는 문항 데이터에 수동 추가 (자동 생성 불가, 교과서 순서 반영).
