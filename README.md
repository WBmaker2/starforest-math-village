# 별숲 수학마을

초등 1~6학년 2학기 수학을 별빛 숲 마을에서 배우는 마을형 수학 웹앱입니다.

## 마을 소개

- 마을 입구 안내(`index.html`): 학년 입구 6종, 학습 도구, 새싹숲(1·2학년), 별숲(3~6학년), 성장 순환, 마을 놀이, 교실 도구함
- 3학년 별숲 마을(`grade3/`): 주민 만들기, 마을 산책, 단원 장소 6곳, 텃밭과 꾸미기, 일지와 기록
- 1·2학년 새싹숲 마을(`lower/`): 큰 그림과 큰 단추로 푸는 산책 마을

## 새로 만든 것

별숲 세계관과 지명, 직접 그린 일러스트와 SVG, 학년별 문항과 단계별 풀이, 교실용 주소 복사.

## 구성

- `index.html`, `assets/css/styles.css`, `assets/js/grades.js`, `assets/js/history.js`, `assets/js/app.js`
- 학년 마을: `grade3/index.html`, `lower/index.html`, `assets/js/g3-*.js`, `assets/css/g3.css`

## 로컬 확인

python3 -m http.server 8000 --directory . 실행 후 http://localhost:8000 열기.
